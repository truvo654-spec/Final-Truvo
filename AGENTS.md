# Project Rules & Instructions

## Versioning & GitHub
- Every time an update or feature is completed on this applet, bump the project version in `package.json` (e.g. following semantic versioning `0.1.0`, `0.1.1`, `0.2.0`, etc.).
- Maintain changelog / version history notes if appropriate so the user can easily sync or push the updated version to their GitHub repository via the AI Studio GitHub export / sync feature.
